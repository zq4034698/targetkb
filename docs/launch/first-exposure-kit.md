# TargetKB: First Exposure Kit

Use this kit for the first public mentions of TargetKB. Keep the links natural: one primary link per post is enough. Do not post the same text word-for-word on multiple communities.

## 1. Indie Hackers launch post

**Title**

I built a free image compressor for the annoying “must be under X KB” upload limit

**Body**

I kept running into upload forms that reject an image because it is 12 KB too large. Most image compressors make you guess a quality percentage, then upload again, then guess again.

So I built TargetKB: a small browser-based tool where you enter the limit you were given — 50 KB, 100 KB, 200 KB, 1 MB, or any other size — and it finds a smaller image that fits.

It also supports batch compression for up to 10 images, resizing, square cropping, and JPG / PNG / WebP / HEIC conversion. The common workflows are included too: forms, email attachments, WordPress uploads, job applications, Discord, and WhatsApp.

The first version is free and does not require an account. Images are processed locally in the browser whenever possible.

I would love blunt feedback on two questions:

1. Which upload limit causes you the most pain?
2. Is there a workflow I should build next: PDF, passport photos, or something else?

Try it here: https://targetkb.com/compress-image-to-100kb
