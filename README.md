# TargetKB

Free, privacy-first image tools for real upload limits.

**Live site:** [targetkb.com](https://targetkb.com)

TargetKB helps people compress, resize, crop, and convert images directly in a browser. It is built around the problem users actually have: making an image fit a specific upload limit such as 50KB, 100KB, 200KB, or 1MB.

## What it does

- Compress images to an exact KB or MB target
- Batch compress up to 10 images
- Convert HEIC, JPG, PNG, and WebP images
- Resize and center-crop images before compression
- Start from practical workflows for forms, email, websites, WordPress, job applications, Discord, and WhatsApp
- Process images locally in the browser whenever possible
